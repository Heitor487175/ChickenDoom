# Chicken Doom

## Download para Linux

[Baixar o ZIP com o AppImage](https://github.com/Heitor487175/ChickenDoom/releases/latest/download/ChickenDoom-AppImages.zip)

O arquivo é publicado nos GitHub Releases, não no histórico do repositório.

## Publicar uma nova versão

Depois de enviar o workflow para `main`, publique uma tag no formato `v*` para gerar o AppImage e publicá-lo automaticamente:

```sh
git tag v1.0.0
git push origin v1.0.0
```
